# Security policy

## Supported versions

PortWatch is pre-release. Security fixes are applied to the latest development version until the first stable release policy is published.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting for this repository. If that is unavailable, contact a maintainer privately and include affected versions, reproduction steps, impact, and any suggested mitigation.

Never include real credentials, private paths, or sensitive process data in a report. You should receive acknowledgement within seven days. We will coordinate disclosure after a fix is available.

PortWatch never silently elevates privileges. A report involving process termination must use a harmless process owned by the reporter.
